Keeps Inkwell book-author metadata and reading-list data available when themes change.

== Description ==

Inkwell Books registers the book_author taxonomy, bibliographic WooCommerce
product fields, author-aware product search, and the privacy-aware reading-list
forms used by the Inkwell theme.

The Inkwell theme includes backward-compatible fallbacks, so activating this
plugin does not interrupt an existing store. Install and activate the plugin
before changing themes to keep the data interfaces available.

Shortcodes:

* [inkwell_newsletter]
* [inkwell_newsletter_unsubscribe]
